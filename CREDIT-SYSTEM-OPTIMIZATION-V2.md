### 1.2 行业定价模式分类

#### 📌 **模式 A: 纯订阅制 (Subscription-only)**
**代表**: Character.AI, Replika, MyAnima  
**特点**: 
- $10-$20/month for core features  
- Annual billing with 20-70% discount  
- No per-feature consumption  

**适合场景**: Text chat focused apps with consistent usage

#### 📌 **模式 B: 订阅 + 消耗制 (Hybrid Credit System)**
**代表**: Candy AI, DreamGF, GirlFriendGPT, goloveai  
**特点**:
- Subscription base ($13-$20/month)
- **Monthly credit allowance included**
- Per-feature costs (images/videos use extra credits)
- Optional top-up packages

**适合场景**: Multi-media platforms (text + image + video)

#### 🌟 **模式 C: 游戏化行动点 (Daily Action Points)**
**代表**: AIKO (Android)  
**特点**:
- Free tier: 100 AP/day (~20 messages)
- Optional IAP for more AP
- No mandatory subscription

**适合场景**: Gamified experience with natural pacing

## 💵 三、收入模型与盈利性分析

### 3.1 单用户生命周期价值 (LTV) 测算

假设用户分布（基于行业基准）:
```
Free tier:        60% of total users (free attracts traffic)
Pro tier:         30% of paid users
Premium tier:     15% of paid users (NEW!)
Unlimited tier:    5% of paid users (high-end enthusiasts)
```

**月度收入预测** (per 1,000 users):
```
Free:    600 × $0      = $0
Pro:     180 × $9.99   = $1,798
Prem:     90 × $24.99  = $2,249
Unlim:    30 × $34.99  = $1,050
───────────────────────────────
Total MRR = $5,097 ≈ $5.10 ARPU
```

**对比原方案**:
```
Old: 600×$0 + 240×$9.99 + 100×$29.99 = $5,396 (ARPU: $5.40)
New: 600×$0 + 180×$9.99 +  90×$24.99 +  30×$34.99 = $5,097 (ARPU: $5.10)
```

**结论**: LTV 微降 **5.5%**，但换取了：
- ✅ 更好的用户体验和转化率
- ✅ 减少用户抱怨"价格跳跃太大"
- ✅ Premium tier 捕获原本会流失的重度用户
- ✅ 净收益持平或略升（因 Premium 可能超过预期渗透率）

### 3.2 盈亏平衡分析

#### Pro 用户 ($9.99/month)
```
Monthly Revenue:    $9.99
Monthly Credits:    1,500
Estimated Usage:    1,350 (90%)
Revenue per Credit: $0.00740

GPU Cost Estimate:
- Image Gen: $0.045 × 135 = $6.08 (assuming 80% images)
- TTS:       $0.005 × 135 = $0.68 (assuming 10% TTS)
- Video:     $0.25 × 135 = $33.75 (assuming 10% videos, avg 50cr)
───────────────────────────────────────
Total GPU Cost:  ~$40.51 (Wait! This exceeds revenue!)

Corrected Analysis:
Heavy video usage breaks unit economics. Adjust expectation:
- 80% images:  1080 @ 9cr  = 9,720 credits
- 15% TTS:      81 @ 1cr   =   81 credits
- 5% light vid:  54 @ 50cr = 2,700 credits
───────────────────────────────────────
Total:          = 12,501 (impossible with 1500 allowance)

Realistic Mix:
- 70% images:   1,050 @ 10 = 10,500 credits
- 20% TTS:      300 @ 1   =    300 credits
- 10% vids:      60 @ 50  =  3,000 credits
───────────────────────────────────────
Wait, this still exceeds... 

Final Realistic Model:
User consumes exactly allowance = 1,500 credits
Split: 
- 1,200 credits worth images = 120 images × $0.045 = $5.40
- 100 credits worth TTS = 100 messages × $0.005 = $0.50
- 200 credits worth videos = 4 videos × $0.50 = $2.00
───────────────────────────────────────
Total GPU Cost: $7.90
Gross Profit:   $2.09 (21% margin) ← Acceptable!
```

**Key Insight**: Must ensure average user doesn't overuse expensive features like video. Use rate limits and warnings.
